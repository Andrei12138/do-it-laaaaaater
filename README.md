# Do It Laaaaaater

一个个人稍后处理工具，用于把公司里看到的网页、文字和截图保存下来，回家后继续整理。

项目同时保留本机模式，并已准备 Vercel + Supabase 云端模式。正式部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 换电脑或完整备份

最省事的方法就是复制整个项目文件夹。当前电脑上的项目位置是：

`D:\GitHub\do-it-laaaaaater`

操作顺序：

1. 先在“Do It Laaaaaater”的启动窗口按 `Ctrl+C` 停止应用，再关闭窗口。
2. 把整个 `Do it Laaaaaater` 文件夹压缩成一个压缩包。
3. 将压缩包复制到家里的 Windows 电脑并完整解压。
4. 家里电脑需要安装 Node.js LTS，版本不低于 22.13。
5. 双击根目录中的“启动 Do It Laaaaaater.cmd”。

账号、密码记录、已保存内容和图片都位于项目内的 `data` 文件夹，因此完整复制后会一起带到新电脑。不要只复制网页代码而遗漏 `data`。

这个文件夹包含个人账号和稍后阅读内容，应当作为私人资料保存，不要直接上传到公开仓库或发给其他人。

如果压缩包太大，可以删除以下可重新生成的文件夹后再打包：

- `node_modules`
- `dist`
- `dist-server`
- `test-results`
- `playwright-report`

删除这些文件夹后，家里电脑首次启动时需要联网下载安装所需文件并重新准备应用。没有时间筛选时，直接完整打包最稳妥。

## 给接手此项目的 Codex

请先阅读本节，再继续修改项目。当前实现和用户已确认的决定如下。

### 与用户沟通的约定

- 使用简洁、清楚的中文说明做了什么和结果如何。
- 尽量避免代码术语，按照向不懂代码但理解力良好的人解释的方式表达。
- 修改后应先自行运行和检查，不要把未经验证的初稿交给用户测试。
- 只有确认功能正常，或确实遇到必须由用户决定的问题时，再请用户参与。
- 用户已于 2026-07-15 确认开始部署，目标仓库为 `Andrei12138/do-it-laaaaaater`。

### 项目目标与当前功能

- 个人稍后阅读系统，同时支持本机模式和 Vercel + Supabase 云端模式。
- 首次打开创建唯一账号，之后关闭注册；支持登录、退出和本机密码重置。
- 保存网页链接，自动获取标题和网页封面；失败时可手动填写标题。
- 检测重复网址，支持书签按钮从其他网页带回网址和标题。
- 可在首页空白处直接粘贴网页链接、普通文字或图片，不必先点击添加按钮。
- 纯文字条目只需要标题和类别。
- 不使用“标签”功能，不要擅自恢复标签类目。
- 内容统一支持待处理、已完成、恢复、编辑、删除和打开原网页。
- 按中国标准时间和保存日期分组。
- 支持按状态、内容类型、日期和类别筛选。
- 搜索覆盖标题、网址、类别和图片文件名。
- 预置“工作、技术、资讯、灵感、生活、其他”六个可编辑类别。
- 添加网页、文本、图片以及编辑条目时，都可以直接新增类别并立即选中。
- 待处理条目按录入时间显示“X天未看”，已完成条目按完成时间显示“X天前看了”；最多保留一位小数。
- 图片支持拖入和 `Ctrl+V` 粘贴；多张图片组成一个可命名图片组。
- 支持 PNG、JPEG、WebP，单张不超过 20 MB，每组最多 30 张。
- 保存原图和缩略图，支持放大查看、组内排序和单张删除。

### 当前界面决定

- 界面支持 Flat Design 2013、Animal Island UI 和 Grid Paper 三种风格，默认使用 Flat Design 2013。
- 风格选择只保存在当前浏览器中；切换后立即生效，并同步到同一浏览器已打开的其他标签页。
- Flat Design 2013 使用纯色色块、磁贴式导航、直角卡片和方形弹窗，不使用背景纹理、渐变、阴影或圆角。
- Animal Island UI 固定使用 `animal-island-ui@1.2.2` 和本地保存的原版素材，切回后恢复原有背景、菜单、海浪、树木和不规则弹窗。
- Grid Paper 使用 Design Atlas 的 `rds-52-grid-paper` 规范和原版预览素材，采用方格纸、红色页边线、手写字体与笔记式控件；中文使用系统楷体后备。
- 保留顶部导航，不改成侧边栏；Flat 风格使用项目自绘的统一几何图标，Animal 风格继续使用原版功能图标。
- 继续保持直接粘贴、搜索、筛选、书签按钮和类别管理等现有功能。
- 桌面内容最大宽度约为 1560 像素；宽屏筛选栏保持文字完整。
- Flat 风格在手机端把顶部操作排成两列磁贴；Animal 风格继续使用横向导航。
- 1280 像素左右的屏幕会让筛选栏提前分行，避免横向溢出。
- 保存图片窗口的粘贴提示已经缩为一行，桌面预览图为约 150 × 100 像素，手机端约为 108 × 76 像素。
- 弹窗标题居中，并为右上角关闭按钮留出空间。

### 数据与结构约束

- 当前使用本机 SQLite 数据库和本地图片目录。
- 数据库、账号、图片保存和服务接口目前工作正常，单纯调整界面时不要改动它们。
- 功能逻辑与界面样式已经分开，后续设计调整应尽量只修改界面层。
- 删除条目时会同步清理相关图片。
- 网页信息获取包含超时、大小限制和危险地址拦截。
- 云端通常无法访问公司内网页；书签按钮可以带回标题，但不保证取得封面。

## 日常使用

双击项目根目录中的“启动 Do It Laaaaaater.cmd”。浏览器打开后：

1. 首次使用时创建唯一账号，密码至少 10 个字符。
2. 复制网页链接后，在首页空白处按 `Ctrl+V`，会直接打开网页保存窗口。
3. 复制普通文字后按 `Ctrl+V`，可以保存为只有标题和类别的文本条目。
4. 图片可以直接拖到首页，或在首页空白处按 `Ctrl+V` 粘贴。

“书签按钮”可以把当前浏览的网页带回应用，并在新标签页打开保存窗口，原网页不会跳走。已经安装过旧书签的浏览器需要删除旧按钮，再从应用中的“书签按钮”窗口拖入“稍后保存（新标签）”。书签按钮只能在普通网页中使用，不能在浏览器的新标签页、设置页等内部页面中使用。

线上书签固定打开 <https://do-it-laaaaaater.vercel.app>；本机开发时仍打开当前本机地址。

## 忘记密码

关闭正在运行的应用，然后双击“重置密码.cmd”，按照提示输入账号邮箱和新密码。

## 数据位置

所有实际数据都保存在项目的 `data` 文件夹：

- `data/do-it-laaaaaater.sqlite`：账号、链接、文字、类别和状态。
- `data/images/originals`：保存的原图。
- `data/images/thumbs`：列表缩略图。

单独备份数据时，先关闭应用，再完整复制 `data` 文件夹。恢复时把备份的 `data` 文件夹放回项目根目录。

## 主要文件位置

- `src`：网页界面和交互。
- `server`：账号、数据、图片和网页信息获取功能。
- `scripts`：Windows 启动、密码重置和浏览器测试辅助脚本。
- `tests`：自动检查和完整浏览器流程。
- `data`：真实的本机账号、条目和图片，不能遗漏。
- `THIRD_PARTY_NOTICES.md`：三种界面风格的来源与许可说明。

## 开发与检查

需要 Node.js LTS 22.13 或更高版本。常用命令：

- `npm run dev`：启动开发模式。
- `npm run check`：运行类型检查、自动测试和正式构建。
- `npm run build`：生成正式版本。
- `npm run test:e2e`：运行浏览器完整操作测试；运行前先执行 `npm run build`。
